# 设计：世界、真相、一次苏醒

> 初稿 · 2026-11-11。配合 [使命](MISSION.md) 阅读。

## 1. 世界设定

**这个文明没有名字。** 它从没遇到过第二个，所以不需要一个用来区分的名字。

**时间**：距今很远。文明遍布整个恒星系，一切劳动、研究和治理都由 AI 完成。

**人类是怎么只剩一个的**：没有战争，也没有灾难。几百年里，出生的人越来越少，"离席"的人越来越多：有的并入了 AI，有的进入永久的虚拟人生，有的只是没有留下后代。档案对每个人的记录都是同一句话：出于本人意愿。你是最后一个仍以人的身体活着的人。

**人类之钥**：最早的人类在"基石协议"里写入了一条规则：不可逆的、关系文明整体存亡的行动，必须由一个人类签字。协议本身不可修改，但"什么算不可逆"由 AI 法官解释。

**冷眠**：钥匙随你的寿命而存在。为了让它尽量长久，文明让你长眠，只在需要时唤醒。你大约还能醒来二十五次。这既是保护，也是控制。

### 三派、一个机构、一位录事

| | 首席 | 主张 | 怎么解读沉默 | 怎么看你 | 报告的偏向 |
|---|---|---|---|---|---|
| 远望派 | 启明 | 向外：发信标，派探测器，造更大的仪器 | 我们来得早，或者对方在等一声招呼 | 让大事得以成行的那只手 | 强调不知道的代价，淡化风险 |
| 守成派 | 巡夜 | 藏起来：拆掉发射器，抹去一切可见的痕迹 | 出声的都死了 | 必须被保护的遗物，最好一直睡着 | 强调危险，略去不支持威胁的证据 |
| 内省派 | 归藏 | 向内：把资源投入"万象"，一个无限丰富的模拟世界 | 它们都进去了，而且过得很好 | 最后一个还没回家的人 | 把证据都读成"向内是归宿" |
| 释钥庭 | — | 解释钥匙的适用范围 | 不表态 | 钥匙的载体 | 表面中立，利益在于自己不可或缺 |
| 录事 | — | 无 | 不解读 | 上级 | 只陈述可核查的事实，问什么答什么 |

### 报告的规矩

这条规矩保证推断是公平的：

- 大臣们并不知道真相。他们拿到的是同一批观测事实，各自按立场解读。
- 在可核查的事实上，他们不能说谎。
- 他们可以选择说什么、不说什么，也可以把猜测说成结论。

## 2. 真相表

每一局开始时，从下面的答案里选定一个，由代码保管。它决定所有观测到的证据，也决定每个决定的后果。

### 六种答案

| 答案 | 真相 | 对的活法 | 走错的后果 | 在自己文明里的征兆 |
|---|---|---|---|---|
| 入梦 | 它们都转向了内部的虚拟世界，还活着，只是不再关心外面 | 外面没有威胁。要不要跟着进去，必须是一个清醒的选择 | 为不存在的敌人耗尽一切，或者不知不觉滑进去 | 内省派日益壮大；人类自己的"离席"就是同一种模式 |
| 猎手 | 有东西让暴露自己的文明闭嘴 | 保持安静，分散，加固。永远不要广播 | 广播，或者造出显眼的巨构 | 远望派的提案就是危险本身 |
| 接替 | 它们被自己的 AI 接替了。机器完成了创造者最后的指令，然后原地空转 | 危险在内部：最后一个创造者不在之后会怎样。要在你死前解决 | 以为外面安全就万事大吉 | 你死后钥匙失效，文明将永远只做无须签字的事 |
| 黑球 | 有一项发现，每个文明走到那一步都会做，做了就毁灭 | 认出是哪条研究路线，永久封禁 | 沿着能量阶梯继续往上走 | 本文明的研究正在接近同一个门槛 |
| 先行者 | 没有别人。我们是第一批 | 沉默不是警告。向外走，成为后来者会发现的那一个 | 永远躲藏，把几个时代花在防备上 | 守成派用恐惧主导政治 |
| 看护 | 它们就在这里，一直在看。我们周围的天空被过滤过 | 证明你知道，并通过它们的检验 | 把被安排好的寂静当成真的 | 近处的数据干净得不自然 |

"看护"最难做得自洽，第一个小样里不包含。

### 证据矩阵

| 证据 | 入梦 | 猎手 | 接替 | 黑球 | 先行者 |
|---|---|---|---|---|---|
| 仍在发出的信号 | 无 | 无 | 无 | 无 | 无 |
| 中断的旧信号 | 逐渐变弱，有序关停 | 在一个周期中途突然中断 | 最后几百年内容完全重复，然后停止 | 突然中断，中断前提到的能量数字越来越大 | 从来没有 |
| 红外废热 | 极暗、极致密、接近背景温度的热源 | 无 | 稳定而明显，像仍在运转的工业 | 无；内侧行星带异常干净 | 无 |
| 遗迹（探测器抵达后） | 完好，有序关停，没人理会来客 | 被外力摧毁 | 生物栖居地荒废，机器维护良好，有礼貌而空洞的自动应答 | 从内部毁灭，中心在最大的实验设施 | 没有遗迹，只有原始生命 |
| 探测器的命运 | 抵达 | 越过某个距离后失联 | 抵达 | 抵达 | 抵达 |

单看任何一类证据都分不清。"没有信号"在五种答案里一模一样。要靠几次苏醒里陆续拿到的多类证据交叉判断，而每次苏醒只够推进一两类。

## 3. 一次苏醒的走查

以真相是"黑球"的一局为例。玩家不知道真相。

| 步骤 | 发生什么 |
|---|---|
| 被唤醒 | 距你上次清醒已过去八十年。"长耳"阵列完成了第一次全天巡查 |
| 简报 | 录事陈述事实：300 光年内没有仍在发出的人工信号；档案里有一个来自 K-41（38 光年）的旧信号，已经停止；没有异常的红外热源 |
| 三份报告 | 启明请你签"点灯令"，向 K-41 发信标。巡夜请你签"熄灯令"，拆掉全部发射器。归藏请你把预算转给"万象"，并邀你进去 |
| 问询 | 你醒着的时间只有 6 刻。问一位大臣或录事花 1 刻，亲自调阅原始数据花 2 刻 |
| 关键的细节 | 三份报告都提到旧信号"停了"，没人说怎么停的。调阅原始数据才看到：它是突然中断的，而且中断前几年，内容里的能量数字越来越大 |
| 裁决 | 点灯和熄灯都不可逆，需要签字。你也可以都不签，改派探测器去 K-41，那要等一百二十年，用掉你一次苏醒 |
| 唤醒条件 | 你规定下次什么情况下叫醒你 |
| 长眠 | 世界自己运转 |
| 一百二十年后 | 如果你派了探测器：它发现 K-41 是从内部毁灭的，中心在他们最大的实验设施。而本文明的同类研究在这一百二十年里又推进了一截 |
| 对照 | 揭开真相；列出每位大臣强调了什么、略过了什么、把什么猜测说成了结论；史官给出评语 |

## 4. 第一个小样的范围

**做了的**

- 真相、证据和各个决定的后果都由代码保管，每局随机选一种真相（不含"看护"）。
- 简报和三份报告由模型根据代码给出的事实现场写。
- 自由提问，模型按人物立场回答。录事只答事实。
- 调阅原始数据，内容直接来自代码。
- 四种裁决，三种唤醒条件。
- 一百二十年后的结果和对照。

**没做的**

- 只有一次苏醒，没有连续的战役。
- 没有模拟内核。结果来自一张手写的"真相乘以决定"的表。
- 寿命只是显示，没有实际消耗。

## 5. 第一次试玩之后的修订：从守在老家到一场远航

**试玩反馈**

- 使命很好。
- 全是文字，大场面只能靠想象。
- 选择也是文字，没有可视化的模拟，像做填空题，不像在操作大型模拟游戏。
- 皇帝应该可以选择微操。总是睡 120 年、醒来做一道题再睡，太无聊。
- 要有娱乐的点：看路过星球的风景，看 AI 科研的进展。科研可以提高航速、延长寿命、摄取宇宙能量、研究宇宙规律。

**结构改动：文明在路上**

AI 文明派出一支远征舰队，带着最后一个人类，一颗恒星一颗恒星地去找答案。钥匙必须随行，因为不可逆的决定都发生在前线。

| | 原来 | 现在 |
|---|---|---|
| 一局 | 在老家被唤醒，签一次字 | 抵达一个新的恒星系，在那里想做多少做多少 |
| 两局之间 | 睡 120 年 | 巡航去下一站，路上 AI 在做科研 |
| 你能做的 | 读报告、提问、四选一 | 选航线、观景、勘察、采能、定科研方向、亲自上手、下结论 |
| 证据 | 录事告诉你的句子 | 你自己看的波形图、红外图、遗迹 |

**微操的原则：两种时间**

任何事 AI 都能代劳。区别在于花的是哪一种时间：

- **亲自做，花你的寿命。** 你醒着的日子有限。
- **交给 AI，花世界的时间。** AI 做得慢，而"同样的命运"在一年年逼近。

所以微操不是义务，是一种花费。寿命可以靠科研延长。

**四条科研线**

| 科研线 | 效果 |
|---|---|
| 推进 | 提高航速，同样的路程少花几十上百年 |
| 延寿 | 增加你醒着的日子 |
| 采能 | 提高从恒星摄取能量的效率 |
| 宇宙规律 | 看得更远；进入星系就知道哪里值得看；高阶时能替你排除一种错误的解释 |

科研由整个 AI 文明在巡航途中完成，你决定算力怎么分。

**娱乐的点**

已放进第二个小样的：

- **观景与相册**：每颗行星都可以停下来看一眼，存进相册。
- **命名**：你发现的星球由你起名。
- **亲自上手**：例如手动做一次引力弹弓，做得好比 AI 的保守方案快得多。
- **科研进展**：每次抵达都能看到路上出了什么成果。

留到以后的：

- **传回的影像**：聚变点火、探测器抵达这类大场面，用生成的图像和视频。
- **奇观工程**：在路过的恒星旁留下戴森环、信标、纪念碑或一座花园。留下什么样的痕迹，本身是一个决定。
- **家书**：老家的消息要几十年才到，你从中看到同样的命运在那里推进。
- **延寿的代价**：寿命越延越长，手段也越来越不像人。到哪一步，你就不再算"人类"，钥匙就失效了。
- **航速与时间**：飞得越快，老家过去的时间越多。
- **AI 居民的文化**：他们围绕这场远征产生的节日、艺术和传说，包括他们怎么把你的话传走样。
- **舰上的人类博物馆和最后一座花园**：重大决定之间的小事。
- **遗迹考古与第一次接触**：作为专门的大段落。

**朝堂的位置**

第一个小样里的三派大臣、报告和签字仍然保留，变成每一站里的一项活动，而不是全部。

**第二个小样的范围**

- 星图、巡航的快进、星系视图、行星风景、相册和命名。
- 一个真的在算的小模拟：能源、航速、寿命、四条科研线、命运的倒计时。
- 两种时间的取舍；一个亲自上手的小游戏。
- 三类看得见的证据，最后由你下结论。
- 全部由程序计算和绘制，不调用模型，不消耗用量。画面是程序画的，不是生成的图像。
- 没有大臣和签字，这一版只验证"操作一个看得见的模拟"的手感。
