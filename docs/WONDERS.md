# 奇观图鉴与真实感规范

> 初稿 · 2026-11-11。第二个小样的结论是"终于不是在做题了"，但想象力和逼真感还不够。本文是这两件事的设计底本。

## 1. 原则：真实是想象力最好的来源

真实的宇宙比编出来的更离奇，也更让人信。所以奇观优先取自天文学，每一条写明三样东西：你看到什么，它的依据是什么，你能在那里做什么。

依据分三档，游戏内的资料库也照此标注，让玩家学到的东西在游戏外也成立：

- **已观测**：有直接的观测证据。
- **理论**：尚未直接看到，但被广泛接受或认真研究。
- **虚构**：本游戏的设定。

以下条目的依据来自我已有的知识，没有逐条查证，上线前需要懂天文的人审读。

## 4. 别的文明留下的痕迹

这一部分是虚构。每种真相有自己的视觉语言，和一个让人起鸡皮疙瘩的细节。

| 真相 | 遗迹的样子 | 那个细节 |
|---|---|---|
| 入梦 | 完好，整洁，关着灯。中心有一个冰冷致密的黑色结构 | 对接口上还亮着"请稍候"，已经亮了四万年 |
| 猎手 | 轨道上的残骸，断口朝着同一个方向 | 所有残骸的熔痕一样深：对方只用了一击 |
| 接替 | 一尘不染的空城，机器每天清扫 | 餐桌每天摆好，从来没有人来吃 |
| 黑球 | 被烧净的内侧行星带 | 最后一份实验日志的最后一行是"能量再提高一档" |
| 先行者 | 没有遗迹 | 最老的化石只是微生物垫 |
| 看护 | 一切正常 | 同一片星空拍了两次，噪声一模一样 |

## 5. 舰上的生活

- AI 居民从没见过故乡以外的天空，每到一处都有人创作。你可以去看他们画了什么、写了什么。
- 他们围绕你和这场远征形成了节日和传说，也会把你说过的话传走样。
- 舰上有一座人类博物馆和最后一片地球植物。这些是重大决定之间的小事。

## 6. 逼真感从哪里来

| 来源 | 规范 |
|---|---|
| 物理上的真 | 不超光速，航行以年计，通信有延迟。轨道内快外慢。恒星的颜色对应它的类型。行星的类型和它离恒星的距离相称 |
| 模拟上的真 | 一切结果都是算出来的，系统之间互相牵连，没有凭空的数字。同一种真相下，所有证据不互相矛盾 |
| 感官上的真 | 你看到的一切都是仪器读数或传回的影像，带噪点、延迟和标注，没有上帝视角。声音来自冷眠舱、无线电噪声，以及把数据转成的声音 |
| 人物上的真 | AI 居民有一致的记忆和动机，记得你做过什么 |
| 细节上的真 | 具体的数字、单位、日期、仪器名。文书用录事的口吻，不解释寓意 |

## 7. 现在的差距与下一步

小样里的画面是程序画的，物理也是简化的。离"身临其境"差在三处：

1. **画面**。需要用图像和视频生成来做"传回的影像"。先做一次视觉目标测试：选一个星系，按本文的规范生成五张风景和一段抵达的短片，看能不能达到要的水准，以及同一星系的几张图风格是否一致。
2. **物理**。把轨道、恒星类型、行星分布换成符合天文学的模型。
3. **声音**。目前完全没有。

视觉目标测试需要图像或视频模型的密钥，这个环境里没有。
