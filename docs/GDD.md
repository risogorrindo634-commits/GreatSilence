# 《大沉默》游戏设计文档

> v0.2 · 2026-11-11 · 预制作阶段。第 16 节的五项已确认。本文是现行设计的唯一依据。此前的 MISSION、DESIGN、WONDERS 是它的来源，冲突时以本文为准。
>
> 标"待定"的条目需要确认；标"假设"的数值没有经过试玩验证。

## 1. 概述

| 项目 | 内容 |
|---|---|
| 一句话 | 你是最后一位人类执政官，带着一支由 AI 运转的远征舰队逐星航行，在同样的命运降临之前弄清楚：别的文明都去哪了 |
| 类型 | 太空探索模拟，以推理为主线 |
| 平台 | Web 优先，桌面和手机浏览器 |
| 人数 | 单人 |
| 一次游玩 | 10 到 20 分钟，对应一个星系 |
| 一场战役 | 3 到 5 小时，到访 5 到 7 个星系。假设 |
| 重玩 | 每局的星图和隐藏的真相都不同 |
| 目标玩家 | 硬科幻读者；喜欢摆弄系统的模拟和策略玩家；喜欢推理的玩家。中文优先 |

**它和同类的区别**

1. 胜利条件是一个正确的结论，不是积累。
2. 证据是玩家自己读的图和数据，不是系统告诉你的句子。
3. AI 能做一切，玩家决定把有限的寿命花在哪。
4. 居民是有立场的 AI，但真相和事实由代码掌握。
5. 奇观取自真实的天文学。

## 2. 设计支柱

每条支柱都用来裁决取舍。一个功能如果不服务于任何一条，就不做。

| 支柱 | 意味着 | 不意味着 |
|---|---|---|
| 理解才是进展 | 游戏的终点是看懂沉默并做出对的回应 | 不靠刷资源、升级数值通关 |
| 什么都可以不做，也都可以亲手做 | 每件事都有 AI 代劳的方案和亲自上手的方案 | 不强迫微操，也不把玩家晾成看客 |
| 真相由代码掌握 | 证据彼此一致，推理是公平的，模型不能编造事实 | 不让模型决定剧情走向或结果 |
| 真实的宇宙 | 不超光速，航行以年计，奇观有天文学依据 | 不是教科书，允许为好玩做简化，但要标明 |
| 决定收不回 | 重大决定要签字，后果在几十上百年后才显现 | 不提供读档反悔 |

## 3. 玩家体验目标

| 时刻 | 希望玩家感到 |
|---|---|
| 抵达一个新星系 | 好奇，以及"这里从没有人来过" |
| 看一处风景 | 安静的震撼，想把它留下来 |
| 亲手做成一件事 | 我比 AI 的保守方案做得更好 |
| 读一条证据 | 我自己看出来了，没有人告诉我 |
| 证据互相矛盾 | 不安，想去下一站求证 |
| 签字 | 这一步收不回，而且只有我能签 |
| 醒来看到后果 | 原来如此，或者"我当时不该那样" |
| 下结论 | 把一路看到的东西拼成一个解释 |

## 4. 核心循环

三层循环，一层套一层。

**操作循环，几十秒到几分钟**

选一件事 → 决定亲自做还是交给 AI → 付出时间 → 得到结果。

**航段循环，10 到 20 分钟，一个星系**

1. 抵达。简报这一程路上发生了什么：科研、家书、舰上的事。
2. 活动。追线索（调查、调谐）、观景、补给（采集、建设）、亲自上手。
3. 朝堂。如果有需要签字的事，听各派的报告，问询，裁决。
4. 部署。调整科研的算力分配，设定唤醒条件，选下一站。
5. 启航。巡航的快进画面，你在冷眠。

**战役循环，3 到 5 小时，整场远征**

| 幕 | 星系 | 内容 |
|---|---|---|
| 听 | 第 1 到 2 个 | 教学；建立能源和科研的基础；第一条证据；第一次签字 |
| 寻 | 第 3 到 6 个 | 证据在几个星系间积累；各派分歧加深；家书里显出命运的征兆；中途出现一条与你的主要假设相矛盾的证据 |
| 答 | 最后 1 到 2 个 | 下结论，并签署与之对应的回应；看到后果；史官定论 |

## 5. 时间与资源

### 5.1 两种时间

这是整个经济的核心，已由第二个小样验证。

| | 清醒日 | 世界年 |
|---|---|---|
| 是什么 | 你醒着的日子，你个人的预算 | 文明经历的时间 |
| 怎么花 | 亲自做任何事 | 巡航；交给 AI 做任何事 |
| 怎么来 | 延寿科研 | 不能倒回 |
| 花完会怎样 | 你长眠不起，钥匙失效 | 命运降临 |

### 5.2 其他资源

| 资源 | 用途 | 来源 |
|---|---|---|
| 能源 | 跃迁、建设 | 采能阵列、采集燃料 |
| 算力 | 科研速度，按比例分给四条线 | 随能源收入增长 |
| 权威 | 各派是否服从有争议的决定；结局时能否推行你的回应 | 到场、裁决得当；长期沉睡和过度放权会流失 |

### 5.3 命运的压力

界面上只有一根"同样的命运"的进度条。它背后有三个隐藏的驱动：

- **时间**：世界年。
- **显眼度**：能源用量、采能阵列、信标、巨型工程。
- **放权度**：交给 AI 的事占多大比例。

不同的真相给这三者不同的权重。例如"黑球"主要看时间，"猎手"主要看显眼度，"接替"主要看放权度。

显眼度的后果不是立刻兑现的：设施建成后要过几十年才被看见。进度条只显示刻度，不显示数值。这样它是一条要花时间去读的线索，而不是做一次对照实验就能读出的答案。

这样做的目的是让压力本身成为证据：留意进度条在什么时候涨得快，就多了一条判断真相的线索。它还让"亲自做还是交给 AI"这个选择在不同的局里有不同的含义。

风险是玩家可能觉得进度条不讲道理。需要小样验证。

## 6. 系统设计

### 6.1 航行

- 星图是节点式的，一局 8 到 12 颗恒星，间距 5 到 40 光年。
- 航速从 0.1c 起，靠科研提高，上限低于光速。
- 跃迁耗能与距离成正比。
- 引力弹弓给下一程加速，可亲自做，也可交给 AI。
- **唤醒条件**：你规定巡航途中什么情况下叫醒你。条件越宽，花的清醒日越多，但越不容易被架空。
- 航速高时，巡航画面里的星光会变蓝并向前方聚拢。

### 6.2 星系探索

- 每个星系 2 到 5 个天体，外加至多一处来自图鉴的奇观。
- 天体的类型与恒星类型和轨道位置相称：近处是熔岩和岩石，宜居带可能有海洋，冰线以外是气态和冰封世界。

| 活动 | 亲自做 | 交给 AI | 产出 |
|---|---|---|---|
| 观景 | 2 天 | 不可代劳 | 相册、命名 |
| 调查异常 | 8 到 12 天，多步 | 60 年，只得到较粗的结果 | 证据 |
| 采集 | 6 天 | 20 年 | 能源 |
| 建设 | 10 天 | 40 年 | 采能阵列、奇观工程 |

数值是假设。观景不可代劳是有意的：那是只有人会去做的事。

**线索**是主线：每一条说明去哪里看、那里有什么，不说意味着什么；有的线索在途中才出现。哪里有异常由线索指明，不再需要勘察。规则见 SLICE 第 8 节。

### 6.3 科研

四条线，各五级。

| 科研线 | 效果 |
|---|---|
| 推进 | 提高航速 |
| 延寿 | 增加清醒日 |
| 采能 | 提高能源收入 |
| 宇宙规律 | 仪器更好：调谐更清楚，调查更快，探测器更可靠；高阶时排除一种错误的解释 |

- 科研由 AI 文明在巡航途中完成，速度取决于算力和你的分配。
- **需要签字的突破**：某些级别上，AI 科学家会提出一项不可逆的实验，等你签字。在"黑球"的局里，其中一项就是那颗黑球。
- 各派的势力会影响科研：内省派越强，向外的研究越慢。
- 玩家可以亲自参与一次科研，用清醒日换一次进度的跃升。

### 6.4 证据与推理

**证据有六类**：旧信号、红外、遗迹、探测器的命运、对广播的回应、文明消失时的水平。每局出现其中四到五类。

**呈现**：波形、热图、影像、统计图，都由玩家自己看。系统只说"这是什么数据"，不说"它意味着什么"。

**干扰项**：自然现象会伪装成证据，例如脉冲星像一个规律的信号。

**推理板**：一张"真相乘以证据"的表，由玩家自己标注每条证据支持还是反对哪种解释。系统不代填。宇宙规律科研可以替玩家排除一种解释。

**下结论分两步**：

1. 结论：沉默的原因是哪一种。
2. 回应：签署一项与之对应的不可逆行动。

| 真相 | 对的回应 |
|---|---|
| 入梦 | 立下一条规则：向内必须是清醒的选择，文明永远保留一支向外的力量 |
| 猎手 | 永久静默，拆除一切显眼的设施 |
| 接替 | 在你死之前，为文明确立一个不依赖你的目的，或安排钥匙的传承 |
| 黑球 | 永久封禁那一条研究路线 |
| 先行者 | 解除防备，向外播种，留下后来者能发现的标记 |

只说对原因不够，还要有足够的权威把回应推行下去。这把朝堂和结局连在了一起。

### 6.5 朝堂

- 三派：远望、守成、内省。另有解释钥匙的释钥庭，和只陈述事实的录事。
- 每个星系至多出现一件需要签字的事。它由模拟的状态引出，不是随机事件。例如能源充裕时，远望派会提议在这里造一座信标。
- 报告由模型根据代码给出的事实现场写。大臣不知道真相，不能在事实上说谎，但可以挑着说、把猜测说成结论。
- 裁决改变模拟里的参数：显眼度、算力的去向、各派的支持度、你的权威。
- 一派的支持度太低时，会在"可逆"的范围内自行其是。这是被架空的具体形式。

第一个小样里，纯文字的朝堂像在做填空题。所以它在这里只是每一站的一项活动，而且每个裁决都要在模拟里看得见后果。

### 6.6 亲自上手

原则：每个小操作不超过一分钟，有明确的技巧空间，AI 有一个保守的基准方案，而且结果要落到模拟的数值上。

| 操作 | 玩法 | 落到哪里 |
|---|---|---|
| 引力弹弓 | 看准时机点火 | 下一程的航速 |
| 聚变点火 | 调两个量，把等离子体稳在窗口里 | 采能阵列的产出 |
| 信号调谐 | 调频率和相位，把信号从噪声里拉出来 | 旧信号证据的清晰度 |
| 大气取样 | 操纵探测器穿过云带 | 巨行星的调查结果 |
| 选址降落 | 在晨昏线上选一个点 | 调查的清醒日花费 |
| 透镜对焦 | 把舰队停在恒星引力的焦线上 | 提前看清下一站 |

引力弹弓已在小样里验证。其余是设想。哪个不好玩就砍掉哪个。

### 6.7 寿命与钥匙

- 起始约 90 个清醒日。假设。
- 延寿科研的前三级没有代价。
- 之后每一级都让你更不像人。释钥庭可能裁定你已不算人类，钥匙随之失效。

### 6.8 记录

- **相册**：存下的风景。
- **命名**：你发现的天体由你命名，名字留在星图上，AI 居民会沿用。
- **航行日志**：自动生成的编年记录。
- **史官的定论**：结局时的评语，可以分享。

## 7. 结局

| 结局 | 条件 |
|---|---|
| 明断 | 结论对，回应对，权威足够 |
| 知而不能行 | 结论对，但权威不够，回应推行不下去 |
| 侥幸 | 结论错，但签下的回应恰好无害或有益 |
| 失察 | 结论错，回应造成损失 |
| 未决 | 命运先到 |
| 长眠 | 清醒日用完 |
| 失钥 | 延寿过度，或权威归零，钥匙失效 |
| 入梦 | 接受内省派的邀请，退出 |

每个结局之后有一段尾声：两百年后的故乡是什么样子。

## 9. 叙事

- **世界**：这个文明没有名字，因为它从没遇到过第二个。人类没有被消灭，是一个个自愿"离席"的。
- **语气**：克制，具体，不解释寓意。文书用录事的口吻。
- **叙事的载体**：简报、报告、家书、遗迹里的记录、日志。没有过场动画式的旁白。
- **人写的**：世界设定、真相表、各派立场、每种真相的遗迹和那个关键细节、奇观的描述。
- **生成的**：大臣的报告和回答、科学家的笔记、居民的创作、史官的评语、家书的措辞。

## 10. AI 的使用

| 由代码决定 | 由模型生成 |
|---|---|
| 真相、证据、每个决定的后果 | 大臣的报告和问答 |
| 模拟里的一切数值 | 科研笔记、家书、居民的创作 |
| 数据的图像：波形、热图、星图 | 史官的评语 |
| 需要签字的事何时出现、是什么 | 这些事的措辞 |

- 模型只拿到它该知道的事实。真相不进入给大臣的提示。
- 模型的输出要过结构校验。失败时用人写的模板兜底，玩家不应感知到故障。
- 高频的问答用小模型，报告和评语用较强的模型。
- 成本目标：每个星系的模型调用不超过十几次。具体数字待垂直切片实测。

## 11. 界面

- **美学**：仪器。玩家看到的一切都是读数或传回的影像，带噪点、延迟和标注，没有上帝视角。
- **主要画面**：星图、星系、风景、科研、朝堂、推理板、相册、日志。
- **信息层级**：常驻的是命运的进度条，纪年、能源、航速、清醒日、权威五个读数，和一行"下一步"：按线索告诉玩家该去哪里、做什么，点它就去那里。每个按钮上标明它花的是哪一种时间、花多少。
- **手机**：单栏，所有操作单手可达。
- **上手**：第一个星系是带引导的，一次只教一件事。

## 12. 美术与声音

- 现阶段的画面由程序绘制，够用来验证玩法。
- 成品的大场面走"传回的影像"，用图像和视频生成，由统一的美术规范约束。
- 声音包括冷眠舱的环境声、无线电噪声，以及把数据转成的声音。
- 视觉目标测试推迟到垂直切片的灰盒完成之后。

## 13. 技术概要

- TypeScript。模拟内核是确定性的，由种子驱动，可以重放。
- 内容是数据：真相表、星系模板、奇观、事件，都与代码分离，便于调整。
- 模型走供应商适配层，沿用之前的决定：多供应商，高频调用用小模型。
- 存档先放在本地。
- 完整的架构文档在本文确认之后重写。

## 15. 风险

| 风险 | 应对 |
|---|---|
| 推理太容易或太难 | 用正确率来调证据的清晰度；引入干扰项 |
| 小操作像噱头 | 每个都必须落到模拟数值上；不好玩就砍 |
| 朝堂又变回填空题 | 只由模拟状态引出；裁决的后果必须在模拟里看得见 |
| 模型不可靠或太贵 | 事实由代码掌握；模板兜底；小模型承担高频调用 |
| 范围失控 | 点子很多。垂直切片的范围锁定，其余进"以后"清单 |
| 画面达不到要的水准 | 在生产之前做视觉目标测试 |
| 科学内容出错 | 上线前请懂天文的人审读；游戏内标明依据的档次 |
| 重玩价值不足 | 真相、星图、各派势力三者的组合 |

## 16. 已确认的事项

以下五项于 2026-11-11 按建议确认：
