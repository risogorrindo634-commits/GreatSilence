# 试玩（M1 灰盒切片）

这一轮试玩回答 GDD 第 14 节 M1 的验收标准：

- 5 位试玩者各打完一局；
- 至少 3 位愿意再玩；
- 推理正确率在四成到七成之间。太高说明证据太直白，太低说明不公平。

另外看两件 GDD 和切片规格里悬而未决的事：一局是不是 45 到 60 分钟；命运的三个隐藏驱动会不会让人觉得不讲道理（GDD 第 16 节：会的话就退回只看时间）。

## 1. 准备

1. **发布。** 在仓库的 Settings → Pages 里把 Source 设为 GitHub Actions，再到 Actions 页面运行 Pages 工作流。地址一般是 `https://risogorrindo634-commits.github.io/GreatSilence/`，以 Pages 设置页上显示的为准。
2. **冻结版本。** 五个人用同一个版本，试玩期间不改规则。对局记录里带着版本号，汇总时会核对。
3. **分配真相。** 运行 `npm run playtest -- --seeds`，按它列出的种子给每人发一个带 `?seed=` 的链接，例如入梦两人、猎手两人、黑球一人。不要用 `?truth=`，它会把真相写在链接里。种子打开后就从地址栏去掉了，刷新页面会接着玩。
4. **找人。** 最好有人没玩过推理游戏。手机和电脑都可以。

## 2. 发给试玩者的话

把链接填进去，原样发出去：

> 这是一个还在做的游戏，叫《大沉默》，画面都是占位的。想请你打一局，大约 45 到 60 分钟，手机或电脑都行。
>
> 链接：（填在这里）
>
> - 用平常的浏览器打开，不要用无痕窗口。中途关掉了，再打开同一个链接会接着玩。
> - 不用查攻略，也不用问我怎么玩。看不懂、拿不准的时候，照你自己的理解做下去，这正是我想知道的。
> - 打完有三个问题。答完点"复制对局记录"，把复制的内容发给我；复制不了就点"存成文件"，把文件发给我。
> - 玩到一半不想玩了也没关系：到"记录"页点"复制到目前为止的对局记录"发给我，说一句为什么停下。
> - 记录里只有你的操作、用时和你写的字。

## 3. 在旁边看

能当面看，或者开着屏幕共享，就尽量看着玩：在哪里犹豫、读错了什么，对局记录里看不出来。

- 不提示，不解释。被问到怎么玩，就回答"你觉得呢"，然后把这个问题记下来。
- 记下时间和看到的事，例如"12 分，在遗迹的图上停了很久，说'这是被炸的？'"。

值得留意的地方：

| 时候 | 看什么 |
|---|---|
| 开头五分钟 | 分得清清醒日和世界年吗？第一次在"亲自做"和"交给 AI"之间选，犹豫吗？ |
| 读证据 | 看图还是只看文字？哪一条读错了？用了推理板没有？ |
| 命运的进度条 | 有没有盯着格子猜真相，说出"它涨得快，所以是……"这类话？ |
| 朝堂签字 | 签之前在推理，还是随手点？结局揭晓陷阱时，反应是"原来如此"还是"凭什么"？ |
| 小操作 | 玩过一两次之后，是不是全交给 AI 了？ |
| 情绪 | 哪里笑了、皱眉、走神、拿起手机。 |

打完之后再聊五分钟：

1. 用一句话说说，这个游戏是干什么的？
2. 你是在哪一刻确定结论的？
3. 有没有哪一步，你觉得是游戏骗了你，而不是你自己想错了？
4. 命运的进度条，你是怎么用的？
5. 跟朋友提起它，你会怎么说？

## 4. 汇总

1. 把收回来的文字和文件放进仓库根目录的 `playtest/` 目录。整段聊天记录粘进一个文件也行，脚本会从中找出对局记录；同一局既发了文字又发了文件，只算一次。`playtest/` 不会被提交，因为里面有试玩者写的字。
2. 运行 `npm run playtest`。它把每一局重放一遍，列出：
   - 每一局的真相、结论、回应、结局、用时、拿到了哪些证据、亲自做和交给 AI 各几件、签了什么；
   - 对照 M1 三条标准的结果，以及用时的中位数；
   - 每一局停得最久的三处，停完之后做了什么；推理板上留下的标记；三个问题的答案。
3. 推理正确率的算法：结论对的局数除以打完的局数。没下结论就结束的局（未决、长眠）算错。
4. 脚本提示记录的版本和当前不一致时，先 `git checkout` 到记录里的那个版本，再汇总。

## 5. 看完结果怎么调

数值都在 `src/content/balance.ts`，证据的文字在 `src/content/truths.ts`。一次只改一处，改完再试玩一轮。

| 看到的 | 先查 | 再动 |
|---|---|---|
| 正确率高于七成 | 大家说是靠哪条证据定下来的 | 降低那条证据的清晰度（例如 `tune.detailAt`），或者让干扰项更像真的 |
| 正确率低于四成 | 读错的是哪条证据，怎么读错的 | 改那条证据的画法或措辞，不要加提示 |
| 一局明显短于 45 分钟，或长于 60 分钟 | 步数，停得久的地方 | 航程、清醒日、科研的速度 |
| 有人靠进度条猜出了真相 | 他是在什么时候、看到几格时猜的 | `fate.exposureYears` 加长，或者减少 `fate.segments` |
| 觉得命运不讲道理 | 结局的分层图让他明白了没有 | 按 GDD 第 16 节，退回只看时间 |
| 几乎全交给 AI | 是小操作不好玩，还是亲自做不划算 | 小操作的手感，或亲自做的收益 |
| 不愿再玩 | 先听原因 | 原因弄清楚之前不动数值 |
